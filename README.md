# Restaurant-Table-Reservation-and-Takeaway-2025
This is a C program that allows user to reserve a table or takeaway at the restaurant.

Description :
1) Greeting and User Options:
 Upon launch, the program greets the user and provides two options:
  a)Reserve a table.
  b)Place a takeaway order.

2) Table Reservation:
 If the user opts to reserve a table:
 The user enters their name, contact details, and the number of people (up to 4).Based on the number of people, the program lists available tables, allowing the user to select one. If a valid table is selected, the reservation details are displayed.

3) Takeaway Order:
  i) The user specifies whether they are a premium member.
  ii) Premium members can access a special menu with discounted prices.
  iii) Non-premium members can access the regular menu.
   The menu is divided into three categories:
    a)Drinks
    b)Pasta and fritters
    c)Desserts
  The user can order multiple items by specifying the item number and quantity of each element.

5) Billing:
  After placing an order, the program calculates and displays: Ordered items.
Quantity of each item.
Cost of each item.
 The total bill amount is displayed at the end.
